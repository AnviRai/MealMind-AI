Food Recommendation System

About the Project

This is a simple food recommendation system that I made while learning about Python and machine learning. The main idea behind this project is to help people choose food according to their budget, food preferences and other requirements.

Sometimes it becomes difficult to decide what to order, especially when there are multiple people and a fixed budget. This project tries to make that decision easier by suggesting suitable food options.

Features

- Recommends food based on the user's budget.
- Includes vegetarian and non-vegetarian options.
- Allows users to select their preferred cuisine.
- Takes meal type and number of people into account.
- Provides food suggestions based on the selected preferences.
- Uses a simple interface built with Streamlit.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

Project Structure

- "app.py" - Contains the application interface.
- "model.py" - Contains the food recommendation logic.
- "Data/" - Contains the dataset used by the project.

How to Run the Project

1. Clone this repository or download the project files.

2. Install the required Python libraries.

3. Open the project folder in VS Code.

4. Run the following command in the terminal:
   
   "python -m streamlit run app.py"

5. The application will open in your browser.
